# Glossar Sicherheitsbeleuchtung (mit INOTEC-Begriffen)

| Begriff | Bedeutung |
|---------|-----------|
| **Allgemeinbeleuchtung (AV)** | Die normale Beleuchtung. Wird aus der allgemeinen Stromversorgung gespeist. |
| **Antipanikbeleuchtung** | Sicherheitsbeleuchtung für große Flächen ohne festgelegte Wege. Mind. 0,5 lx. |
| **Batteriebetrieb** | Die Anlage versorgt die Leuchten aus der Batterie (216 V DC). Auslöser: Netzausfall am Hauptverteiler, Funktionstest, Betriebsdauertest. |
| **BCS** | Battery Control System (INOTEC): überwacht jeden Batterieblock (Spannung, Temperatur). |
| **Bereitschaftslicht (BL)** | Die Leuchte ist im Normalbetrieb aus und geht nur bei Ausfall der Allgemeinbeleuchtung an. |
| **Betriebsdauertest (BT)** | Batterietest über die volle Nennbetriebsdauer. Jährlich. |
| **Betriebsgerät** | Elektronik in der Leuchte (LED-Treiber + Kommunikationsmodul). Bei FUSION mit fester ID. |
| **Blockieren** | Notlicht oder Dauerlicht gezielt unterdrücken, z. B. außerhalb der Nutzungszeit. |
| **Brandabschnitt** | Durch Brandwände begrenzter Gebäudeteil. Im Sinne der MLAR mind. jedes Geschoss bzw. jeder Treppenraum, max. 1.600 m². |
| **CF-Modul** | Stromkreisumschaltung der CPS FUSION (CF 4x1A, 2x2,5A, 1x5A). |
| **CP-Modul** | Stromkreisumschaltung der Vorgänger (CPS 220/64) bzw. 24-V-Modul der FUSION (CP 2x2,5A/24V). |
| **CPS** | Central Power Supply System = Zentralbatterieanlage (ohne Leistungsbegrenzung). |
| **CPUS** | Unterstation der CPS FUSION mit eigener Steuerung, ohne Ladeteil, mit Netz- und Batterieleitung vom Hauptgerät. |
| **CPUSB** | BUS-Unterstation: ausgelagerte Stromkreismodule, versorgt über eine 3-adrige Leitung in E30, gesteuert über IB2. |
| **D.E.R.** | Dynamic Escape Routing: INOTEC-System zur dynamischen Fluchtweglenkung. |
| **Dauerlicht (DL)** | Die Leuchte ist immer an, im Netz- und im Notbetrieb. |
| **DPÜ / DPÜ/B** | Dreiphasenüberwachung (ohne/mit Bus): erkennt Phasenausfall im Unterverteiler der Allgemeinbeleuchtung. |
| **E30 / Funktionserhalt** | Ein Kabel bzw. Verteiler funktioniert im Brandfall mind. 30 Minuten weiter. |
| **Einzelbatterieleuchte (EB)** | Leuchte mit eigener Batterie (selbstversorgt). Batterie ≥ 4 Jahre. |
| **Endstromkreis** | Stromkreis von der Anlage zu den Leuchten. Max. 20 Leuchten, max. 60 % Auslastung. |
| **Ersatzbeleuchtung** | Notbeleuchtung zum Weiterarbeiten. Keine Sicherheitsbeleuchtung. |
| **Erhaltungsladung** | Kleiner Ladestrom, der die volle Batterie voll hält. |
| **Fernschalter (FS)** | Eingang zum externen Blockieren. |
| **Funktionstest (FT)** | Kurzer Test im Batteriebetrieb: Umschaltung + jede Leuchte. Wöchentlich/monatlich. |
| **Handrückschaltung** | Notlicht schaltet nach Netzwiederkehr erst nach manueller Quittierung ab (verdunkelte Räume). |
| **HVA / HVS** | Hauptverteiler der Allgemeinbeleuchtung / der Sicherheitsbeleuchtung. |
| **IB1/IB2/IB3** | INOTEC-Gerätebusse (intern / extern / nur DPÜ/B). |
| **INOWeb / INOView** | Weboberfläche im Steuerteil / zentrale Überwachungssoftware. |
| **Isolationsüberwachung** | Erkennt Erdschluss in den Stromkreisen im Batteriebetrieb (< 470 kΩ). |
| **JOKER** | INOTEC-Mischbetrieb (seit 1998): Dauer- und Bereitschaftslicht im selben Kreis, eingestellt am Leuchtenmodul. |
| **Konfigurator** | Windows-Software zum Programmieren der Anlage. |
| **Learn-Mode** | Neues Einlernen der Referenzströme der Leuchten (z. B. nach einem Leuchtentausch). |
| **LPS** | Low Power Supply = Gruppenbatterieanlage (max. 1.500 W/1 h bzw. 500 W/3 h). |
| **LSA** | Lichtschalterabfrage-Modul (LSA 3.1, LSA 8.1). |
| **Lux (lx)** | Einheit der Beleuchtungsstärke (Lumen pro m²). |
| **MTB** | Fernmeldetableau (grün/gelb/rot + Schlüsselschalter). |
| **Nennbetriebsdauer / Systembetriebsdauer** | Wie lange die Sicherheitsbeleuchtung bei Netzausfall mindestens leuchten muss (1 h, 3 h, 8 h …). |
| **Netzausfall UV** | Ausfall in einer Unterverteilung der Allgemeinbeleuchtung. Die Leuchten gehen an, versorgt aus dem Netz über die CPS. |
| **Notlichtnachlauf** | Die Sicherheitsbeleuchtung bleibt nach Netzwiederkehr noch eine Zeit an (bis 15 min). |
| **OGi** | Bauart ortsfester Bleibatterien (Gitterplatten). Bei INOTEC als verschlossene Blockbatterie. |
| **Prüfbuch** | Dokumentation aller Tests, Störungen und Änderungen. Elektronisch im Steuerteil, Pflicht nach EN 50172. |
| **RIF 5** | INOTEC-Modul: Meldekontakte, Fernschalter, Stromschleife, Temperaturfühler, HV-Überwachung. |
| **RTG** | 3-adriger INOTEC-Datenbus für externe Überwachung/Tableaus. |
| **Rettungszeichenleuchte** | Hinterleuchtetes grünes Rettungszeichen (Piktogramm). |
| **Sicherheitsleuchte** | Leuchte, die Flucht- und Rettungswege ausleuchtet. |
| **SLÜ** | Schleifenüberwachung (Stromschleife auf Kurzschluss und Unterbrechung überwachen, mit Zener-Abschluss). |
| **Stromschleife (SL)** | 24-V-Ruhestromschleife zu den DPÜs. Wird sie unterbrochen, geht das Licht an. |
| **Tiefentladeschutz** | Trennt die Last von der Batterie, bevor sie zu tief entladen und beschädigt wird (Test bis 185 V). |
| **Umschaltzeit / Aktivierungszeit** | Zeit vom Netzausfall bis zum Erreichen der geforderten Beleuchtungsstärke. |

## Betriebsmittelkennzeichen (Schaltplan lesen, Folge 4)

Vorzeichen (DIN EN 81346-1, früher DIN 40719): **`=`** Anlage/Funktion, **`+`** Ort, **`-`** Betriebsmittel (Produkt). Das Minus vor `-F101` ist also kein Minuspol.

Gebräuchliche Kennbuchstaben. **Achtung:** Die Normausgaben (DIN 40719, EN 81346-2:2009, IEC 81346-2:2019) haben einzelne Buchstaben unterschiedlich belegt. Verbindlich ist die Legende im jeweiligen Plan.
| Buchstabe | Bedeutung | Beispiele aus der Praxis |
|---|---|---|
| **F** | Schutzeinrichtung (Sicherung, Leitungsschutz) | INOTEC Modulsicherungen; Gessler -2F1 Netz, -2F4/-2F5 Batterie; Kaufel -F101…-F103 Netz, -F111/-F112 Batterie |
| **X** | Klemme, Steckverbinder | INOTEC X1 Netz, X2 Bus, X3 Endstromkreise; Gessler -2X1 |
| **A** | Baugruppe, Modul | Kaufel -A101 = Unterstation US 10; Gessler 2A10, 2A11 (E/A-Module) |
| **K** | Relais, Überwachungsrelais (ältere Pläne auch Schütze) | -K03 … „Spannungsüberwachung“ in einer Unterverteilung |
| **Q** | Leistungs-/Lasttrennschalter (neuere Pläne auch Schütze) | |
| **G** | Energiequelle (Batterie; je nach Plan auch Netzteil/Ladegerät) | |
| **T** | Transformator, Umformer (je nach Plan auch Netzteil) | Ladetransformatoren |

Nummern-Logik: Gleiche Zählnummer heißt oft „gehört zusammen“ (Kaufel: -A101 Unterstation ↔ -F101 ihre AC-Sicherung). Unterverteilungs-Legenden zählen oft je Vorsicherung: `41F3` = dritter Abgang hinter Vorsicherung `F41`.

**UC** (Universal Current, Allstrom): Eingang für Wechsel- **und** Gleichspannung, z. B. an der Kaufel-Unterstation: AC aus der CPS im Netzbetrieb, DC im Batteriebetrieb. Beim Messen AC **und** DC prüfen.
